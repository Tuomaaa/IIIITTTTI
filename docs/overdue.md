# Overdue / 推后 behavior 设计（草案，等你拍板）

> demo 里已经按这份草案实现了一版，可以边看网页边看这个文档。最后一节是需要你决定的问题。

## 要同时满足的几件事

1. 能给你**提醒**；
2. 在功能上**有体现**，看得见；
3. 能确定**推多久**比较合理；
4. 推后**不能是没有代价的**，不然 deadline 就没意义了。

## 核心原则

**推后必须是一个显式的决定，而且永久留痕。**

系统不会偷偷帮你把 task 往后挪。过期了就让它"挂"在那儿、每天变得更难看，直到你（或者你让我）做一次推后决定。
每一次推后都会被记下来（推了几天、哪天决定的、为什么），之后一直显示在甘特条上。

## 规则

| 对象 | 过期时会怎样 | 你需要做什么 |
|---|---|---|
| **todo** | 自动滚到今天，显示 `↻N`（拖了 N 天）。不用你确认，因为 todo 太碎，每个都问会很烦 | 拖到 **≥3 天**会变红进「需处理」，这时必须处理：今天做 / 改期 / 升级成 task / 扔 backlog / 删 |
| **soft task** | **不动**。甘特条在 end 之后长出一段**红色斜纹尾巴**，每天变长一格，旁边写「过期 N 天」 | 推后 或 完成。推后时系统给建议值（见下） |
| **hard task / hard ◆** | **不能推**。条的右端是红色竖条，过期后整条进「需处理」最上面 | 只能完成、砍 scope、或者确认 missed |
| **同一个 task 推了 ≥3 次** | 进「需处理」，标「推太多」 | 不再允许简单推后，要拆小或砍 scope |

## 推多久

建议值 = **剩余工作量**，但**单次最多 2 天**（`maxPushDays`，你说的「每次往后推个一两天」）：

```
剩余工作量 R = 计划天数 × (1 − 进度)，至少 1 天
            计划天数 = focus 天数（没有的话就是窗口长度）
            进度     = 手动填的进度，没填就用挂在它上面的 todo 完成比例
建议新 end  = 今天 + min(R, 2) − 1
```

- R ≤ 2：直接推 R 天，推后新增的那几天自动标成 focus day（等于你承诺了哪几天做）。
- R > 2：系统仍然只建议推 2 天，同时提示「剩余工作量超过单次上限，建议先拆小或砍 scope」。
  如果你坚持一次推得更多，网页上**必须写原因**才能提交。

这样做的好处：小步推，每一步都要重新面对一次；想一次性推一大段，就得说清楚为什么。

## 代价 / 负反馈（让推后"不免费"）

1. **红尾巴每天变长**：不处理，它就每天更显眼。
2. **永久的推迟标记**：条旁边的 `+7d×3` 一直在（累计推了 7 天、推了 3 次），颜色随次数升级：黄 1 次 → 橙 2 次 → 红 ≥3 次。
3. **baseline 虚线**：原定的 end 位置一直画着一条虚线，推了多远一眼就能看出来。
4. **「推迟记录」面板**：本周推了几次、几天；每条线程累计推了多少天（横向条形图），能看出哪条线最爱拖。
5. **顶栏指标**：「本周推迟 N 次 M 天」常驻在顶栏，推得多会变色。
6. **推后会占用未来的容量**：推后新增的天会变成 focus day，算进每日并行数。推多了，未来几天的负载格子会变红，挤占别的线程。
7. **第 3 次之后不能简单推**：必须拆小 / 砍 scope。

## 提醒渠道（选一个或几个）

| 方式 | 怎么工作 | 代价 |
|---|---|---|
| A. 网页本身 | 打开就看到「需处理」和顶栏的红色数字 | 你不打开就看不到 |
| B. 跟我聊的时候 | 每次你找我，我先跑 `summary`，主动把过期 / 拖延的东西拿出来问你推多少天 | 你不找我就没有 |
| C. 每天定时提醒 | 我设一个每天早上的 scheduled task：读数据、把今天的过期项整理成一条通知推到你手机（或发邮件），附上建议推几天 | 要你同意我建这个定时任务；每天会跑一次 |

我的建议：**A + B 默认就有，C 你觉得需要再开**。C 的好处是真正做到"提醒"，坏处是又多一个每天响一次的东西，容易被忽略。

## 需要你拍板的问题

1. 单次推后上限 2 天可以吗？还是 1 天更狠一点？
2. 「推 ≥3 次就不能再推」会不会太严格？还是改成 ≥3 次后每次推都必须写原因？
3. todo 拖 3 天变 stale 合适吗？
4. 要不要开 C（每天早上的定时提醒）？如果要，几点？推到手机还是邮箱？
5. 推后时我（agent）是**先问你再推**，还是你授权我**按建议值直接推、事后告诉你**？
